# Sales MIS Dashboard — Aryan Traders Pvt. Ltd.

## Project Overview
End-to-end MIS Dashboard project for FMCG Distribution company.
Period: January 2025 – June 2025 | 550+ rows of sales data

## What I Built
- Raw data cleaning using Power Query
- Daily, Weekly & Monthly MIS Reports with SUMIFS date filtering
- Interactive Excel Dashboard with 4 Charts, 3 Slicers, 4 KPI Cards
- Business Insights identification

## Tools Used
MS Excel | Power Query | Pivot Tables | SUMIFS | MySQL | Data Visualization

## Key Insights
- North Region leads revenue — Rs 7.52L
- Detergent dominates at 45% category share
- Delivery rate at 56.5% — improvement needed
- Priya Sharma — Top performing salesman
